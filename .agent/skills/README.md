# WaliKelas Tools — Antigravity UI Skills

Workspace-specific skills for `.agent/skills/`.

Recommended structure:

.agent/
└── skills/
    ├── walikelas-ui-system/
    │   └── SKILL.md
    ├── walikelas-shadcn/
    │   └── SKILL.md
    ├── walikelas-motion/
    │   └── SKILL.md
    └── walikelas-frontend-review/
        └── SKILL.md

These skills are intentionally separated:
- UI system = visual language
- shadcn = component implementation rules
- motion = animation rules
- frontend review = audit/refactor workflow

Copy the `.agent/skills/` directory into the root of the tools.walikelas.id workspace.
